Here are some of my projects

  • My First E-Portfolio

    HTML, CSS

    A personal developer portfolio built with HTML and CSS to introduce myself, highlight my developing skills, and present my frontend projects. The site includes an introduction, a technology showcase, project preview cards, and links to my GitHub, email, and resume. I added CSS animations, hover effects, and keyboard focus styles to make the page more engaging and easier to navigate. Responsive layouts adjust the typography, spacing, and project cards for desktop, tablet, and mobile screens.

  • Treact Landing Page

    HTML, CSS, JavaScript

    A responsive landing page built with HTML, CSS, and JavaScript, inspired by the Treact design. The page includes a hero section, six feature cards, three pricing plans, a testimonial section, and a multi-column footer. I used CSS Flexbox and media queries to adapt the layout for desktop, tablet, and mobile screens, along with JavaScript to control the mobile navigation menu. This project helped me practice organizing larger page layouts and creating consistent styling across multiple sections.

  • Library Bookstore

    HTML, CSS, JavaScript

    A responsive bookstore interface built with HTML, CSS, and JavaScript. The page displays 12 books across featured and latest-book sections, with cover images, titles, star ratings, and pricing. I used CSS Flexbox and media queries to adjust the book displays from four columns on larger screens to a single column on phones. JavaScript-powered mobile navigation and CSS hover effects add interaction, while reusable styles keep the design consistent throughout the page.
